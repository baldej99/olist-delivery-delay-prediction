# Прогнозирование задержек доставки Olist

Проект по прогнозированию задержек доставки заказов интернет-магазина на данных бразильского маркетплейса Olist.

## Постановка задачи

Цель проекта — построить модель машинного обучения, которая определяет, будет ли заказ доставлен позже обещанной даты.

Прогноз должен формироваться на момент подтверждения заказа. Поэтому при создании признаков будут использоваться только те данные, которые доступны к этому моменту.

## Данные

В проекте используется открытый датасет **Brazilian E-Commerce Public Dataset by Olist**.

Датасет содержит несколько связанных таблиц с информацией о:

* заказах;
* товарах;
* покупателях;
* продавцах;
* платежах;
* доставке;
* географическом расположении покупателей и продавцов.

Исходные файлы датасета не хранятся в репозитории.

## Структура проекта

* `data/raw/` — исходные данные без изменений;
* `data/processed/` — подготовленные данные для анализа и обучения моделей;
* `notebooks/` — исследование данных и эксперименты;
* `sql/` — SQL-запросы для подготовки данных;
* `src/` — переиспользуемый код на Python;
* `models/` — сохранённые модели;
* `reports/figures/` — итоговые графики и визуализации.

## Текущий этап

Создание структуры репозитория и первичное изучение данных.
